# projeto-frontend

## Sobre o projeto
Projeto da disciplina de Desenvolvimento Front-End para Web. Consiste em uma página inicial simples, usada para praticar versionamento com Git e GitHub seguindo o padrão GitFlow.

## Tecnologias utilizadas
- HTML5
- Git e GitHub
- Visual Studio Code

## Pré-requisitos
- Git instalado (verifique com `git --version`)
- Um navegador web atualizado

## Instalação
Clone o repositório:
```
git clone https://github.com/Mateus5603/projeto-frontend.git
```

## Como executar
O projeto não possui dependências nem etapa de build. Basta abrir o arquivo `index.html` no navegador.

## Testes
Não há testes automatizados. A página pode ser verificada manualmente com o Lighthouse do Chrome e navegando por ela apenas com as teclas Tab e Shift+Tab.

## Organização das branches
- `main`: versões estáveis, marcadas com tags (v1.0.0, v1.1.0)
- `develop`: desenvolvimento contínuo
- `feature/`: novas funcionalidades
- `hotfix/`: correções urgentes
